# 📊 Sales Performance Dashboard | Tableau

## 📌 Project Overview

This project is an interactive *Sales Performance Dashboard* built using *Tableau*. The dashboard analyzes Superstore sales data and provides meaningful business insights through interactive visualizations. It helps understand sales performance, profit, orders, regional performance, product performance, and monthly sales trends.

## 🎯 Project Objectives

- Analyze overall business performance.
- Track Total Sales, Total Profit, and Total Orders.
- Monitor Monthly Sales Trends.
- Identify Top Performing Products.
- Compare Sales and Profit by Category.
- Analyze Regional Sales Performance.
- Visualize Sales by State using an interactive map.
- Build an interactive dashboard to support business decision-making.
